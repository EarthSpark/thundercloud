## Contributing to ThunderCloud

1. Push your code as a branch in the `sparkmeter` repository.
2. From the GitLab UI, create a new merge request:
	* Give it a descriptive title
	* Load th the `default` description template (selected from the dropdown below the title input).
	* Complete the MR template, ensuring you've completed the checklist
		* Items can be checked by replacing `[ ]` with `[x]`.
	* All MRs must have a corresponding ticket in Clubhouse. The `[chXXXXXX]` reference must be updated with
	  the ticket number.
3. Assign the MR to a team member, and ping them on Slack.
4. When approved, rebase and merge your code!
